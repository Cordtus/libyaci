## 2026-10-05 — Correctness/robustness hardening pass

- Progress:
  - Retry now applies only to transient gRPC codes
    (`Unavailable`, `DeadlineExceeded`, `ResourceExhausted`, `Aborted`);
    application errors return immediately. Block-height probes use a zero retry
    budget.
  - `GetEarliestBlockHeight` / binary search distinguish a pruned height from a
    transient error instead of treating every error as "too low".
  - `Dial` no longer aborts when one reflected file fails to register; skipped
    files are recorded and exposed via `Client.SkippedFiles()`.
  - `WithProtoDir` is attached to a clone of the fallback registry, so the
    shared/global or caller-owned registry is not mutated. The directory is
    validated eagerly.
  - `CreatePatchedResolver` no longer does network I/O under the resolver lock,
    resolves fallback and `ProtoDir` types, and includes local-proto dependencies
    so multi-file packages patch correctly.
  - `GetTxsByHeight` follows pagination and preserves the last page's pagination
    metadata.
  - `FindExtensionByName` / `FindExtensionByNumber` implemented by walking
    extension declarations.
  - Streaming methods return a clear error instead of a raw gRPC failure.
  - Added `WithDefaultTimeout` / `InvokeWithTimeout`; default max recv size is now
    16MB.
  - `EachPage` aborts on a repeated pagination key (seen-set, not just
    consecutive).
  - CLI gained `-protodir` and `-json`.
  - Docs: migrated `CLAUDE.md` into `AGENTS.md` and deleted it; marked
    `docs/repository-analysis/` historical; created this dev-docs tree.
- Decisions:
  - Keep reflection as the sole source of truth for callable methods; local
    protos are for decoding only.
  - Keep unary-only support explicit rather than silently failing.
  - Prefer a lazy connection and document that `WithDialTimeout` bounds
    descriptor fetching, not the TCP dial.
- Blockers: none.
- Next: optional future work (not scheduled): streaming RPC support, batch
  requests, and a machine-readable catalog for agent tooling. Residual test gap:
  retry-stop, `GetTxsByHeight` pagination, and binary-search transient handling
  are covered at the predicate/unit level rather than end-to-end against a mock
  server.
